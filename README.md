# ClassRosterOrganizer

Created as a sorting device for students' classes to be transferred to a physical notebook.

## Objectives:
* Notebook has 33 lines (34 if you count the top)
* Classes need to be in order by day-time.
* Alphabetize the names of students in each class.
* Minimize the number of pages needed to write all classes in the notebook.

Outputs as .txt or .xlsx.
Uses xlsxwriter library for .xlsx option.
